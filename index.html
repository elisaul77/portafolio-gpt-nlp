    📊 ¿Cómo leer esta visualización?

    Este diagrama muestra cómo un Transformer decide a qué palabras prestar atención al procesar una oración. De izquierda a derecha: cada palabra de entrada (Input) genera una pregunta (Query, azul). Esa pregunta se compara con todas las demás palabras (Key, verde) para calcular un peso de relevancia (0 a 1). Finalmente, los contenidos semánticos (Value, amarillo) se combinan proporcionalmente a esos pesos para producir el Output. Click en cualquier palabra para ver cómo cambian los pesos de atención.

    📊 ¿Cómo leer esta visualización?

    Esta gráfica muestra las dos mitades de la arquitectura Transformer original. El Encoder (azul, izquierda) procesa toda la entrada simultáneamente — es la base de modelos como BERT. El Decoder (verde, derecha) genera texto token por token — es la base de modelos como GPT. La línea amarilla (Cross-Attention) conecta ambos: el decoder consulta la salida del encoder para generar respuestas informadas. En la práctica, GPT usa solo el decoder y BERT usa solo el encoder; la arquitectura completa se usa en modelos de traducción como T5. Pasa el cursor sobre cada componente para ver su función.
